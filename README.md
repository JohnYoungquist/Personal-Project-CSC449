# Personal Project - CSC449

This repository is the starting point for my CSC449 personal project. It contains the project documentation and will hold source code as development progresses.

## Project board

Track work on the [Personal Project - CSC449 board](https://github.com/users/JohnYoungquist/projects/1).

Use the board to organize tasks through Todo, In Progress, and Done. The repository and board are private, so collaborators need appropriate access.

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/JohnYoungquist/Personal-Project-CSC449.git
   cd Personal-Project-CSC449
   ```
2. Define the project goals and requirements.
3. Create issues for planned tasks and add them to the project board.
4. Develop changes on feature branches and open pull requests for review.

## Current status

Repository initialized with this README and linked to a GitHub project board. Application code, technology choices, and setup instructions will be added as the project develops.
